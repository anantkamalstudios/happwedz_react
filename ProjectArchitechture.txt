SECTION 1 — SYSTEM OVERVIEW
────────────────────────────────────────────────────────────────────────────────

HappyWedz is a full-stack wedding planning SaaS platform. It connects Users
(couples planning their wedding) with Vendors (wedding service businesses) and
provides a rich suite of tools for every aspect of wedding planning.

ACTORS / ROLES:
  1. Guest          — Public, unauthenticated visitor
  2. User           — Registered couple/wedding planner (JWT, 2-day expiry)
  3. Vendor         — Registered wedding business (JWT, decoded from token)
  4. Super Admin    — Separate admin project (manages platform, CMS, approvals)

TECH STACK SUMMARY:
  - Frontend:   React 19, Vite, Redux Toolkit, React Router v7
  - HTTP Client: Axios (axiosInstance with request/response interceptors)
  - Auth:        JWT Bearer tokens stored in localStorage
  - State Mgmt:  Redux slices: auth, vendorAuth, location, wishlist, role,
                 favorites, filters, guestToken
  - UI:          MUI, Bootstrap 5, React Bootstrap, Framer Motion
  - Media:       Fabric.js (canvas editor), Firebase (storage), face-api.js
  - Payments:    Razorpay (flight booking)
  - Maps:        Leaflet / React Leaflet
  - 3rd Party:   Google OAuth, reCAPTCHA, Pannellum (360° view), Chart.js

  8. Vendor can now access full dashboard features
